Taller: Implementación y Verificación de Patrones GoF

En este taller práctico implementamos dos patrones esenciales en el módulo de facturación y notificaciones universitarias: Strategy para la tarificación de becas, Factory Method para la selección de canales de mensajería, y Builder para la creación inmutable del comprobante.

🎯 Requerimiento Funcional: Liquidación y Notificación Universitaria

El sistema debe liquidar los aranceles de matrícula aplicando diferentes fórmulas de becas o descuentos (que pueden ampliarse en el futuro sin modificar la lógica principal) y despachar el comprobante formal al estudiante mediante su canal preferido (Email, SMS o Push Notification).

♟️ 1. Implementación del Patrón Strategy (Cálculo de Descuentos)

Strategy Pattern en Java 21 / Spring Boot 
package ec.edu.unibe.siga.facturacion.strategy;

import java.math.BigDecimal;

public interface DescuentoStrategy {
    String getCodigo();
    BigDecimal calcularDescuento(BigDecimal subtotal);
}

@Component
public class BecaAcademicaStrategy implements DescuentoStrategy {
    public String getCodigo() { return "BECA_ACADEMICA"; }
    public BigDecimal calcularDescuento(BigDecimal subtotal) {
        return subtotal.multiply(new BigDecimal("0.40")); // 40% de cobertura
    }
}

@Component
public class DescuentoProntoPagoStrategy implements DescuentoStrategy {
    public String getCodigo() { return "PRONTO_PAGO"; }
    public BigDecimal calcularDescuento(BigDecimal subtotal) {
        return subtotal.multiply(new BigDecimal("0.10")); // 10% de ahorro
    }
}

@Component
public class SinDescuentoStrategy implements DescuentoStrategy {
    public String getCodigo() { return "REGULAR"; }
    public BigDecimal calcularDescuento(BigDecimal subtotal) {
        return BigDecimal.ZERO;
    }
}

🏭 2. Implementación de Factory Method (Canales de Mensajería)

Factory Method desacoplado 
package ec.edu.unibe.siga.notificacion.factory;

public interface Notificador {
    void enviar(String destinatario, String mensaje);
}

public class EmailNotificador implements Notificador {
    public void enviar(String destinatario, String mensaje) {
        System.out.println("[SMTP TLS] Enviando email a " + destinatario + ": " + mensaje);
    }
}

public class SmsNotificador implements Notificador {
    public void enviar(String destinatario, String mensaje) {
        System.out.println("[TWILIO SMS] Enviando mensaje a " + destinatario + ": " + mensaje);
    }
}

@Component
public class NotificadorFactory {
    public Notificador crearNotificador(String canal) {
        return switch (canal.toUpperCase()) {
            case "SMS" -> new SmsNotificador();
            case "EMAIL" -> new EmailNotificador();
            default -> throw new IllegalArgumentException("Canal no soportado: " + canal);
        };
    }
}

🔨 3. Patrón Builder: Entidad Inmutable Liquidación

LiquidacionMatricula.java (Builder Pattern) 
package ec.edu.unibe.siga.facturacion.model;

import java.math.BigDecimal;
import java.time.LocalDateTime;

public final class LiquidacionMatricula {
    private final String codigoOrden;
    private final String estudianteId;
    private final BigDecimal subtotal;
    private final BigDecimal descuento;
    private final BigDecimal totalPagar;
    private final LocalDateTime fechaEmision;

    private LiquidacionMatricula(Builder builder) {
        this.codigoOrden = builder.codigoOrden;
        this.estudianteId = builder.estudianteId;
        this.subtotal = builder.subtotal;
        this.descuento = builder.descuento;
        this.totalPagar = builder.subtotal.subtract(builder.descuento);
        this.fechaEmision = LocalDateTime.now();
    }

    public static class Builder {
        private String codigoOrden;
        private String estudianteId;
        private BigDecimal subtotal = BigDecimal.ZERO;
        private BigDecimal descuento = BigDecimal.ZERO;

        public Builder conCodigo(String codigo) { this.codigoOrden = codigo; return this; }
        public Builder paraEstudiante(String id) { this.estudianteId = id; return this; }
        public Builder conSubtotal(BigDecimal sub) { this.subtotal = sub; return this; }
        public Builder conDescuento(BigDecimal desc) { this.descuento = desc; return this; }

        public LiquidacionMatricula build() {
            if (codigoOrden == null || estudianteId == null) {
                throw new IllegalStateException("Datos incompletos para liquidación");
            }
            return new LiquidacionMatricula(this);
        }
    }
    // Getters inmutables...
}

🧪 4. Pruebas Unitarias Automatizadas con JUnit 5

LiquidacionServiceTest.java (JUnit 5) 
@SpringBootTest
class LiquidacionServiceTest {

    @Autowired
    private List<DescuentoStrategy> estrategias;

    @Test
    void debeAplicarDescuentoBecaAcademicaCorrectamente() {
        DescuentoStrategy strategy = estrategias.stream()
            .filter(s -> s.getCodigo().equals("BECA_ACADEMICA"))
            .findFirst()
            .orElseThrow();

        BigDecimal subtotal = new BigDecimal("1000.00");
        BigDecimal descuento = strategy.calcularDescuento(subtotal);

        assertEquals(new BigDecimal("400.00"), descuento);
    }

    @Test
    void debeConstruirLiquidacionInmutableConBuilder() {
        LiquidacionMatricula liq = new LiquidacionMatricula.Builder()
            .conCodigo("ORD-2026-001")
            .paraEstudiante("EST-7744")
            .conSubtotal(new BigDecimal("800.00"))
            .conDescuento(new BigDecimal("80.00"))
            .build();

        assertEquals(new BigDecimal("720.00"), liq.getTotalPagar());
    }
}
