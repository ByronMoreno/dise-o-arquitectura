Taller UML 2: Diagramas de Secuencia y Modelo de Contexto C4

En este taller práctico implementamos los flujos de interacción dinámica y la arquitectura de contenedores para el proyecto integrador de software, utilizando especificaciones formales y código PlantUML.

⏱️ Entregable 1: Diagrama de Secuencia con Manejo de Excepciones

El siguiente script en PlantUML modela el flujo integral de validación de materias, cálculo arancelario y pago con pasarela externa bajo el estándar UML 2.5:

secuencia_completa_siga.puml 
@startuml
skinparam style strictuml
autonumber "[00]"

actor "Estudiante" as est
boundary "Portal Web (React)" as ui
control "MatriculaController" as ctrl
control "MatriculaService" as svc
entity "MatriculaRepository" as repo
boundary "PasarelaPagosClient" as payment

est -> ui : Click en "Confirmar e Inscribir"
activate ui

ui -> ctrl : POST /api/v1/matriculas (materiasIds, metodoPago)
activate ctrl

ctrl -> svc : procesarInscripcion(estudianteId, materiasIds)
activate svc

loop Por cada materia seleccionada
    svc -> svc : validarPrerrequisitos(materiaId)
    svc -> svc : verificarCupoDisponible(materiaId)
end

alt Alguna validación falla
    svc --> ctrl : throw CupoAgotadoException()
    ctrl --> ui : 409 Conflict ("Cupo no disponible")
    ui --> est : Mostrar alerta en rojo
else Validaciones Exitosas
    svc -> repo : guardarMatriculaTemporal(estado=PENDIENTE)
    activate repo
    repo --> svc : matriculaGuardada
    deactivate repo

    svc -> payment : cobrarArancel(montoTotal, tokenTarjeta)
    activate payment
    payment --> svc : Response(status="SUCCESS", authCode="TX-5511")
    deactivate payment

    svc -> repo : actualizarEstadoMatricula(id, estado=CONFIRMADA)
    svc --> ctrl : MatriculaConfirmadaDTO
    ctrl --> ui : 201 Created (Comprobante PDF URL)
    ui --> est : Pantalla de éxito con descarga de comprobante
end

deactivate svc
deactivate ctrl
deactivate ui
@enduml

🔄 Entregable 2: Máquina de Estados del Ciclo de Vida de la Matrícula

estados_matricula.puml 
@startuml
skinparam state {
    BackgroundColor #0f172a
    BorderColor #06b6d4
    FontColor #f1f5f9
    ArrowColor #38bdf8
}

[*] --> BORRADOR : Estudiante inicia selección

state BORRADOR {
    BORRADOR : entry / inicializarListaMaterias()
    BORRADOR : do / calcularArancelEnTiempoReal()
}

BORRADOR --> VALIDANDO : Enviar a confirmación
VALIDANDO --> RECHAZADA : [Fallo prerrequisitos o cupo]
RECHAZADA --> BORRADOR : Modificar selección

VALIDANDO --> PENDIENTE_PAGO : [Validaciones Aprobadas] / reservarCuposTemporales(15 min)

state PENDIENTE_PAGO {
    PENDIENTE_PAGO : entry / iniciarTimerExpiracion()
}

PENDIENTE_PAGO --> ANULADA_POR_TIMEOUT : [Tiempo > 15 min sin pago] / liberarCupos()
PENDIENTE_PAGO --> PAGADA : Evento: PagoConfirmado(authCode)

PAGADA --> ASIGNATURAS_ASIGNADAS : Generar actas académicas
ASIGNATURAS_ASIGNADAS --> [*] : Matrícula Activa y Vigente
ANULADA_POR_TIMEOUT --> [*]
@enduml

🗺️ Entregable 3: Diagrama de Contexto y Contenedores (Modelo C4)

Código PlantUML utilizando la librería oficial C4-PlantUML:

c4_contexto_siga.puml 
@startuml
!include https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/C4_Container.puml

Person(estudiante, "Estudiante", "Estudiante de pregrado o posgrado matriculado en UNIBE")
Person(docente, "Docente", "Profesor titular que califica y gestiona asistencias")
Person(admin, "Administrador", "Personal de secretaría y registro académico")

System_Boundary(c1, "Sistema Integral de Gestión Académica (SIGA)") {
    Container(spa, "Single-Page Application", "React / TypeScript", "Interfaz web moderna y responsiva para usuarios")
    Container(api, "Backend API Gateway / Core", "Java / Spring Boot", "Orquesta la lógica de matrícula, seguridad y aranceles")
    ContainerDb(db, "Base de Datos Relacional", "PostgreSQL 16", "Almacena historiales, mallas curriculares y matrículas")
    Container(broker, "Broker de Eventos", "RabbitMQ / Kafka", "Manejo asíncrono de notificaciones y facturación")
}

System_Ext(erp, "ERP Financiero Institucional", "Sistema contable institucional y tesorería")
System_Ext(pasarela, "Pasarela de Pagos (Stripe/Datafast)", "Procesamiento de pagos en línea con tarjetas")
System_Ext(email, "Servidor SMTP / SendGrid", "Envío de confirmaciones y alertas transaccionales")

Rel(estudiante, spa, "Consulta oferta y se matricula", "HTTPS/TLS")
Rel(docente, spa, "Registra notas y asistencia", "HTTPS/TLS")
Rel(spa, api, "Llamadas a endpoints REST", "JSON/HTTPS")
Rel(api, db, "Lectura y escritura transaccional", "JDBC / JPA")
Rel(api, broker, "Publica eventos: MatriculaConfirmada", "AMQP")
Rel(api, pasarela, "Solicita cobro de aranceles", "REST / HTTPS")
Rel(broker, erp, "Sincroniza comprobantes contables", "REST API")
Rel(broker, email, "Despacha notificaciones a estudiantes", "SMTP")
@enduml
