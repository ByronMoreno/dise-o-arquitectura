1. Evolución de las Arquitecturas de Frontend

El desarrollo web ha transitado desde la renderización estática en servidor hacia el procesamiento masivo de JavaScript en el cliente (SPA), y ahora experimenta una convergencia híbrida (SSR/SSG e Islas de Interactividad) para mitigar la sobrecarga de descarga en navegadores móviles:

🌐

SPA (Single Page Application)

Carga un único archivo HTML vacío y un archivo JavaScript pesado. El cliente renderiza y genera el DOM dinámicamente mediante el navegador. Ofrece transiciones fluidas pero penaliza la velocidad inicial y el SEO.

⚡

SSR y Meta-frameworks

Meta-frameworks (Next.js, Nuxt) pre-renderizan el HTML en un servidor Node.js por petición antes de enviarlo al cliente. El navegador recibe una página visual inmediata que luego se activa mediante un proceso llamado Hidratación.

🏝️

Islas de Interactividad

Propuesto por Astro. Todo el sitio web es HTML estático sin JavaScript por defecto. Solo las regiones de UI dinámicas declaradas explícitamente (ej. un carrito) se descargan e hidratan de forma independiente como "islas".

2. Catálogo e Interactividad de Frameworks

Haz clic en cada botón para explorar el tipo de herramienta, su filosofía de reactividad, sus pros y sus contras:

Angular

Framework

Framework de Google opinado y completo. Provee enrutamiento, cliente HTTP, validación de formularios e inyección de dependencias de forma nativa sin depender de librerías de terceros.

Fortalezas (Pros)

  • Estructura corporativa uniforme.
  • Inyección de dependencias integrada.
  • Tipado de TypeScript robusto nativo.

Debilidades (Cons)

  • Curva de aprendizaje empinada.
  • Tamaño del bundle inicial pesado.
  • Demasiado verboso para proyectos pequeños.

3. Comparación de Código: Componente Contador

Compara la sintaxis y la filosofía de gestión de estado reactivo necesaria para codificar un componente contador de clics simple: 

import { useState } from 'react';

export default function Contador() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Clicks: {count}</p>
      <button onClick={() => setCount(count + 1)}>Incrementar</button>
    </div>
  );
}
import { Component } from '@angular/core';

@Component({
  selector: 'app-contador',
  template: `
    <div>
      <p>Clicks: {{ count }}</p>
      <button (click)="incrementar()">Incrementar</button>
    </div>
  `
})
export class ContadorComponent {
  count = 0;

  incrementar() {
    this.count++;
  }
}
<template>
  <div>
    <p>Clicks: {{ count }}</p>
    <button @click="incrementar">Incrementar</button>
  </div>
</template>

<script setup>
import { ref } from 'vue';
const count = ref(0);

function incrementar() {
  count.value++;
}
</script>
<script>
  let count = 0; // Svelte trata declaraciones como reactivas por defecto
  function incrementar() {
    count += 1;
  }
</script>

<div>
  <p>Clicks: {count}</p>
  <button on:click={incrementar}>Incrementar</button>
</div>
import { createSignal } from 'solid-js';

export default function Contador() {
  const [count, setCount] = createSignal(0); // Reactividad sin Virtual DOM

  return (
    <div>
      <p>Clicks: {count()}</p>
      <button onClick={() => setCount(count() + 1)}>Incrementar</button>
    </div>
  );
}
