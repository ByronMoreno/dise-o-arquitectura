## 🎨 Características de los Diagramas Gráficos Incluidos

1. **Mermaid Integrado (`mermaid`):** Se renderiza de forma nativa en GitHub, GitLab, VS Code, Obsidian y cualquier lector moderno de Markdown sin necesidad de plugins externos.
2. **PlantUML (`plantuml`):** Bloques de código fuente listos para compilar en IDEs o herramientas de generación documental.
3. **Fichas Técnicas Formales:** Tablas detalladas con precondiciones, postcondiciones, flujo principal y flujos alternativos.
4. **Guías Mnemotécnicas:** Comparativas visuales de buenas prácticas vs. errores comunes.
