S

Single Responsibility Principle (SRP)

Metáfora: "El Chef Pulpo que cocina, cobra, limpia y reparte en moto al mismo tiempo."

¡SOCORRO! 😵 ¡Tengo que freír hamburguesas, calcular el IVA, guardar en PostgreSQL y enviar 1,000 correos a la vez! ¡Si el cliente cambia de salsa... se cae la base de datos!

📖 La Metáfora de la Vida Real

Imagina un restaurante donde el Chef también cobra en la caja, limpia los baños y hace las entregas en motocicleta. Si se le pincha una llanta en la calle, nadie cocina en el local.

Regla de Oro: Una clase debe tener un solo motivo de cambio. Si el formato de factura cambia, solo debería tocarse la clase de facturación.

Principio: Responsabilidad Única
❌ Código Monstruo: PedidoService.java Java 21 / Spring Boot 
@Service
public class PedidoService {
    // ❌ 4 RAZONES PARA CAMBIAR EN UNA SOLA CLASE
    public void crearPedido(Pedido p) {
        bd.save(p);            // 1. Persistencia
        double total = ...;    // 2. Matemática
        factura.emitir(total); // 3. Facturación
        email.enviar(p);       // 4. Notificaciones
    }
}

📖 La Metáfora de la Vida Real

¿Te imaginas que para jugar un nuevo juego en tu Nintendo Switch tuvieras que abrir la carcasa con un destornillador y soldar chips en la placa madre? ¡Qué locura!

Tu código debe ser como una consola: Cerrado a modificaciones (la consola no se desarma) y Abierto a extensiones (puedes crear 1,000 cartuchos nuevos que encajan en la ranura).

Principio: Abierto / Cerrado
❌ Código Frágil: if / else if en PagoService Java 21 / Spring Boot 
// ❌ CADA NUEVO PAGO EXIGE MODIFICAR ESTE ARCHIVO
if (tipo.equals("TARJETA")) { ... }
else if (tipo.equals("PAYPAL")) { ... }
else if (tipo.equals("CRIPTO")) { ... } // ¡Peligro de romper!
L

Liskov Substitution Principle (LSP)

Metáfora: "Pepe el Pingüino y Aquiles el Águila: no obligues a un pingüino a tirarse de un avión."

¡PLAAAFFF! 🚑 El General me ordenó: "¡Todos los que hereden de Ave deben volar!". Como soy un pingüino, me estrellé y lancé una UnsupportedOperationException.

📖 La Metáfora de la Vida Real

En biología un pingüino es un ave. Pero en software, la herencia se basa en el comportamiento, no en los sustantivos.

Si tienes un método hacerVolar(Ave ave), debes poder sustituir Ave por cualquier subclase sin que el programa explote. Si una subclase no puede cumplir la promesa del padre, la herencia está mal diseñada.

Principio: Sustitución de Liskov
❌ Herencia Rota: Pinguino extends Ave Java 21 / Spring Boot 
public class Pinguino extends Ave {
    @Override
    public void volar() {
        // ❌ ¡COLAPSO EN RUNTIME!
        throw new UnsupportedOperationException();
    }
}
I

Interface Segregation Principle (ISP)

Metáfora: "La navaja suiza de 500 kilos: nadie debería cargar una motosierra solo para cortar un papel."

¡Me pesa demasiado! 🥵 Solo compré una impresora básica de $40 para imprimir tareas, ¡pero la interfaz me obliga a cargar con un escáner industrial y un módem de fax que no tengo!

📖 La Metáfora de la Vida Real

¿Comprarías una navaja de bolsillo que pesa media tonelada porque incluye una rueda de tractor y un taladro percutor?

Es mucho mejor tener interfaces pequeñas y específicas (un cinturón con herramientas individuales: tijeritas, destornillador) que una sola interfaz "gorda" que fuerza a las clases a implementar métodos vacíos.

Principio: Segregación de Interfaces
❌ Interfaz Monolítica Gorda Java 21 / Spring Boot 
public interface Dispositivo {
    void imprimir();
    void escanear();  // ❌ Basura para la básica
    void enviarFax();  // ❌ Basura para la básica
}
D

Dependency Inversion Principle (DIP)

Metáfora: "El enchufe universal de pared: no sueldes tu lámpara a los cables del poste de la calle."

¡Qué desastre! 🔨 Soldé el cable de la lámpara directamente a los cables de alta tensión de la pared con new EmailService(). ¡Para poner una lámpara nueva tengo que demoler la casa entera!

📖 La Metáfora de la Vida Real

Nadie suelda los electrodomésticos a los cables de la pared. En su lugar, existe un contrato universal: el tomacorriente de pared (la interfaz).

Tanto la pared (módulo de alto nivel) como la lámpara o la tostadora (módulos de bajo nivel) dependen del enchufe estándar. Puedes desenchufar el correo y enchufar WhatsApp en 1 segundo.

Principio: Inversión de Dependencias
❌ Acoplamiento Soldado con "new" Java 21 / Spring Boot 
@Service
public class NotificacionService {
    // ❌ SOLDADO DE POR VIDA: Imposible cambiar a WhatsApp
    private final EmailService email = new EmailService();
}
