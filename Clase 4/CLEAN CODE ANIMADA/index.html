El Frasco Misterioso "x"
Antipatrón de Nombres Crípticos
🧪 La Analogía de la Farmacia a Ciegas

Imagina entrar a una farmacia y ver un frasco etiquetado simplemente como "x" con instrucciones que dicen "tomar p con d". ¿Te tomarías esa medicina? ¡Jamás! Eso es exactamente lo que siente otro programador cuando lee calcular(double p, double d). Clean Code exige etiquetas claras: precioBase y porcentajeDescuento.

💥 El Desastre: Nombres que confunden y precisión en peligro

Código con variables mudas de una letra y uso de double para dinero.

ProductoService.java — ¿Qué demonios hace este método? Java 21 / Spring Boot 
public class ProductoService {

    // ❌ Nadie sabe qué es p, ni qué es d, ni por qué retorna x
    public double calcular(double p, double d) {

        double x = p - (p * d / 100);

        return x;
    }
}
🚨 Problema grave: El código no revela su intención. Además, usar double para finanzas produce errores de coma flotante (p. ej. 0.1 + 0.2 = 0.30000000000000004).
La Máquina de Rube Goldberg
Antipatrón de Sobreingeniería
⚙️ La Analogía de Encender una Bombilla

Imagina que para encender la luz de tu sala construyes un sistema donde cae una canica, gira 6 engranes, despierta a un perico y suelta un resorte... ¡cuando sólo necesitabas presionar un interruptor en la pared! KISS (Keep It Simple, Stupid) nos exige eliminar la sobrearquitectura de clases y métodos wrappers inútiles.

💥 El Desastre: 5 Métodos y 1 Clase de Contexto para multiplicar por 0.15

Sobreingeniería cósmica que además introdujo un bug crítico.

CalculadoraIVA.java — Laberinto abstracto de llamadas Java 21 / Spring Boot 
public class CalculadoraIVA {

    // ❌ 4 métodos delegados inútilmente y un Contexto inflado
    public double calcularIVA(double precio) {
        return procesarOperacion(crearContexto(obtenerConfiguracion(validarPrecio(precio))));
    }

    private double validarPrecio(double precio) { return precio; }
    private double obtenerConfiguracion(double precio) { return 0.15; }
    private Contexto crearContexto(double iva) { return new Contexto(iva); }

    private double procesarOperacion(Contexto contexto) {
        // ¡ERROR! Retorna 0.15 sin multiplicar por el precio
        return contexto.getIva();
    }
}
🚨 Trampa de la complejidad: En medio de tantas capas y abstracciones, el autor olvidó multiplicar por el precio base. La complejidad oculta defectos.
Los Clones del Copiar y Pegar
Antipatrón de Lógica Duplicada
👯 La Analogía de la Receta de la Abuela

Si tienes la receta del pastel copiada en tres cuadernos distintos, y la abuela decide cambiar el azúcar por miel... ¡debes buscar los 3 cuadernos! Si olvidas uno, tu pastel sabrá terrible. DRY (Don't Repeat Yourself) centraliza la regla en un único lugar sagrado: un servicio especialista de cálculo.

💥 El Desastre: La fórmula de descuento multiplicada por doquier

ClienteService y ClienteVipService replicando la misma lógica matemática.

ClienteService.java & ClienteVipService.java — Duplicación abierta Java 21 / Spring Boot 
// En ClienteService.java
@Service
public class ClienteService {
    public double calcularDescuento(double precio) {
        return precio - (precio * 0.10); // ❌ Duplicado
    }
}

// En ClienteVipService.java
@Service
public class ClienteVipService {
    public double calcularDescuento(double precio) {
        return precio - (precio * 0.20); // ❌ Duplicado
    }
}
🚨 Riesgo empresarial: Si mañana el descuento cambia a aplicarse tras impuestos, tendrás que editar N clases, aumentando la probabilidad de facturar erróneamente.
El Mochilero Exagerado
Antipatrón de Especulación Prematura
🎒 La Analogía de Ir a la Esquina por Pan

Imagina que vas a la panadería de la esquina a comprar dos panes, ¡pero te pones un traje de buzo espacial, llevas un bote inflable y un botiquín para mordeduras de tiburón por si acaso! YAGNI (You Aren't Gonna Need It) te dice: programa hoy solo lo que el negocio te pidió formalmente hoy.
